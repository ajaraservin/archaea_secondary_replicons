# archaea_secondary_replicons
Code and scripts used for the analysis for the paper Comparative genomics reveals a genomic and functional continuum among secondary replicons in Halobacteriota by Jara-Servin, A. and Toll-Riera, M.
All md documents include bash code used to process and annotate the archaeal genomes. 
The generation of figures and statistics conducted in R are inside the R_analysis directory.
